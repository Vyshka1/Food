# Фотографии блюд

Файлов здесь пока нет — картинки подхватываются автоматически, как только
появятся. Ничего в коде менять не нужно.

## Куда класть

```
src/assets/photos/dish/<id рецепта>.webp   — фото именно этого блюда
src/assets/photos/kind/<категория>.webp    — общее фото на категорию
```

Форматы: `webp`, `avif`, `jpg`, `jpeg`. Лучше `webp` — он в разы легче при
том же качестве.

Не `public/`: там файлы не проходят через сборку, и приложение не смогло бы
узнать, какое фото есть, а какого нет — отсутствующее превращалось бы в
битую картинку и лишний запрос.

## Как выбирается картинка

Своё фото блюда → фото категории → иконка. Категорийное фото подписывается
как «похожее блюдо», а не выдаётся за снимок вашего борща: подмену человек
заметит на кухне, когда его блюдо будет выглядеть иначе.

## Категории

Те же, по которым выбираются иконки (`recipeIcon` в
`src/components/icons.tsx`):

`soup`, `porridge`, `salad`, `bake`, `pan`, `fish`, `meat`, `pancake`,
`drink`, `apple`

Десять файлов в `kind/` закрывают все 78 встроенных блюд.

## Идентификаторы блюд

Первый аргумент каждого рецепта в `src/data/recipes.ts`: `draniki`,
`cod_potato_oven`, `bean_veg_stew`. Полный список с названиями и текущее
покрытие печатает:

```
npm run photos
```

## Лицензии

Годятся стоки, чья лицензия разрешает использование без указания автора:

- **Unsplash** — Unsplash License
- **Pexels** — Pexels License
- **Pixabay** — Pixabay Content License

Не годятся картинки из поиска Google, с кулинарных сайтов и из соцсетей: у
них обычный копирайт, даже если файл открывается без пароля.

Если берёте фото под лицензией с обязательным указанием автора (CC BY,
CC BY-SA с Викисклада), источник нужно перечислить здесь же — иначе через
полгода никто не вспомнит, откуда картинка и что с ней можно делать.

## Размер

Карточка показывает фото полосой примерно 420×180 на плотном экране, то
есть 840×360 достаточно. Держите файл в пределах 60 КБ: 78 фото по 200 КБ —
это 15 МБ, которые придётся качать при каждой установке PWA.
